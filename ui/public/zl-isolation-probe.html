Origin isolation probe (Zeolite beta)

Every check below runs with the exact privileges any same-origin script has on this origin. That includes JavaScript from websites proxied through the same-origin /zl/ or /lj/ frames: they execute on this origin, same as this page. A row reading reachable is something target-site JS can do today. The beta isolation phase must decide which of these to revoke deliberately - never by blindly sandboxing the frame.
